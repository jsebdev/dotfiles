# Mind palaces

A mind palace is a walk through a place you can see, with one object waiting at
each stop. `cloud_needle_isle.py` is the reference example.

## Descriptions Rules

- Name 2 to 4 pegs per room, never more. The rest of the room is left empty on
  purpose, so the story is yours to put there.
- Name them in the same order they sit in `objects`, so reading the description
  walks the room in card order.
- Every peg you name has to be a thing that is in the room right now, it can be still or moving
  The user photographs the room in their mind even if a peg is moving 
- Write the peg word itself into the sentence, so the word and the image are
  welded together.
